Methodology & differentiators

← Overview
WHY CHURNWISE?

Beyond a churn label.

ChurnWise combines predictive scoring, customer-segment context, validation transparency and action-oriented triage in one small deployable application.

◉

Multi-dimensional signals

The supplied dataset has 10,000 rows and 32 columns. Its fields cover customer profile, product engagement, revenue, billing, support, satisfaction, marketing engagement and referrals.

⌁

Validation-first ML

The notebook compares baselines and tree models, tunes parameters with stratified cross-validation, selects a threshold on validation data, and reserves a separate test set for final metrics.

↗

Action-oriented risk

Single-customer scoring returns a probability, configurable risk band and transparent rule-based follow-up suggestions. Batch scoring adds the same outputs to a CSV.

▤

Reproducible artifacts

The saved scikit-learn pipeline bundles preprocessing and the fitted model. The report JSON records threshold and test metrics so the dashboard can reproduce notebook results.

REPRODUCTION PATH

From notebook to web app

01

Explore and validate

Review missing values, duplicates, class balance, numerical distributions, categorical churn rates and feature relationships.

02

Train and compare

Use preprocessing pipelines, stratified splits, candidate classifiers and cross-validated randomized hyperparameter search.

03

Evaluate honestly

Select the threshold on validation data. Report accuracy, balanced accuracy, precision, recall, F1, ROC-AUC, average precision, MCC, log loss and Brier score on the test set.

04

Serve predictions

Flask loads the saved pipeline and uses the same feature order and threshold recorded by the notebook.
